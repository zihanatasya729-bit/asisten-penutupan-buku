# 📚 Asisten Penutupan Buku

Aplikasi web berbasis **Python + Streamlit** untuk membantu proses **month-end / year-end closing** akuntansi: upload trial balance, checklist prosedur, jurnal penyesuaian, rekonsiliasi bank, verifikasi neraca saldo, generate jurnal penutup otomatis, dan export ke Excel.

## ✨ Fitur

| Fitur | Deskripsi |
|---|---|
| 🏠 Dashboard | Ringkasan progress closing, laba/rugi, status keseimbangan |
| 📤 Upload TB | Upload Excel/CSV atau muat data demo |
| ✅ Checklist | 12 prosedur closing interaktif |
| 📝 Jurnal Penyesuaian | Input adjusting entries dengan validasi |
| 🏦 Rekonsiliasi Bank | Saldo bank & buku disesuaikan, deteksi selisih |
| 📊 TB Setelah Penyesuaian | Gabungan TB + adjustments |
| 🔒 Tutup Buku | Generate jurnal penutup otomatis |
| 📥 Export Excel | Semua sheet dalam 1 file |
